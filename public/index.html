¿Cómo funciona?

  1. Compra una licencia en CdKeys Perú.
  2. Inicia la activación por teléfono para obtener el Installation ID (9 grupos de 7 dígitos).
  3. Ingresa tu email de compra y el Installation ID aquí.
  4. Validamos tu compra y generamos el Confirmation ID (CID).
  5. Ingresa el CID en el asistente de activación y listo.
